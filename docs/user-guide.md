## 화면 구성

| 데이터 파일 | 답하는 질문 | 화면 |
|---|---|---|
| `items.csv` | 무엇을 검사하나 (분류 · 규격) | 검사 › 목록, 현황 › 분류별 진행 |
| `placements.csv` + 도면 | 어디에 있나 (도면 · 앞/뒷면) | 검사 › 도면 |
| `recipes.json` + 치수 열 | 기준은 무엇인가 (도면 치수 ± 공차) | 검사 › 기록, 자동 판정 |
| `docs.csv` | 참고할 문서는 | 검사 › 기록 아래 문서 |
| `review` 열 · 빈 위치 · 빈 기준 | 검사 전에 확인할 것 | 현황 › 확인할 것 |
| `model.glb` (PCB) | 실물로는 어디쯤인가 | 현황 · 검사의 3D |

상태는 색, 기호, 글자를 함께 써서 표시합니다.

| 표시 | ✓ | ✕ | ∥ | ◐ | ○ | – |
|---|---|---|---|---|---|---|
| 상태 | 합격 | 불합격 | 보류 | 검사 중 | 미검사 | 검사 제외 |

검사 항목은 `측정`(측정값 입력), `육안`(눈으로 보고 이상 없음 / 이상 선택), `자동`(사람이 확인할 필요 없음)으로 구분해 표시합니다.

## 검사 순서

1. 오른쪽 위 **검사자**에 이름을 넣습니다. 기록마다 이름과 시각이 남습니다.
2. **현황**에서 **검사 시작**을 누르면 남은 첫 항목이 열립니다. 목록에서 직접 골라도 됩니다.
3. **도면**의 파란 칸이 그 항목의 위치입니다. 휠로 확대, 끌어서 이동. 뒷면 · 다른 시트에 있으면 도면이 자동으로 바뀌고, 작은 부품은 자동으로 확대됩니다. PCB 는 **3D** 버튼으로 실물 모양에서도 볼 수 있습니다.
4. **기록**에서 항목마다 기준을 보고 입력합니다.
   - `측정`: 값을 넣으면 허용 범위 막대와 차이(`+0.2 in · 허용 ±0.5 in`)가 바로 나오고 자동 판정됩니다.
   - `육안`: **맞춰 볼 값**(품번 · 규격)과 도면의 **◆**(1번 패드 · 극성 위치)를 보고 **이상 없음 / 이상**.
   - `자동`: 해당 없는 항목과 데이터끼리 비교한 결과입니다. 할 일 없음.
5. 불합격이면 **사유**를 고릅니다. 판단이 어려우면 **보류**에 체크합니다.
6. **다음 미검사**(`N`)로 이어 갑니다. 다 끝나면 **성적서** → **인쇄 · PDF**.

단축키 (검사 화면)

| 키 | 동작 |
|---|---|
| `N` | 다음 미검사 항목 |
| `A` | 비어 있는 '이상 유무' 칸을 모두 이상 없음으로 |
| `Enter` | 수치 입력 중 다음 빈 칸으로 |
| `J` / `K` | 다음 / 이전 항목 |
| `/` | 목록 검색 |
| `Ctrl` / `⌘` + `Z` | 방금 기록 되돌리기 (모든 화면) |
| `?` | 사용 방법 창 (모든 화면) |

> [!NOTE]
> 값을 입력한 뒤 Enter 를 보내는 키보드 방식(HID)의 디지털 측정기는 별도 설정 없이 다음 칸으로 이어서 입력됩니다.

## 예시 1 — PCB (LightSABRE DAC)

1. 현황 › 확인할 것 › *검사 준비 안 됨* 의 `FB1`, `Y1`: 이 분류에는 검사 기준이 없다는 뜻입니다.
2. 검색 `ES9018` → `U5`: 도면 강조, 도면의 ◆ = 1번 패드(DGND), 품번 마킹의 **맞춰 볼 값 ES9018K2M**, 데이터시트 링크.
3. `C1`(세라믹 커패시터): 극성 검사는 자동 '해당 없음'. `A` 한 번이면 합격. 아래 **자동 확인**에 칩 크기 BOM 0603 · CAD 0603 일치.
4. `J6`: 뒷면 부품이라 도면이 뒷면(뒤에서 본 모습)으로 바뀝니다.
5. **3D**: 부품을 누르면 목록 · 기록이 따라오고, '이상'으로 기록한 부품은 빨갛게 표시됩니다.
   3D 의 부품 번호는 패키지 · 위치로 맞춘 것이고 색은 부품 종류별로 지정한 것입니다 (원본 STEP 에 둘 다 없음).

## 예시 2 — 용접·가공 도면 (LifeTrac III)

1. 현황 › 확인할 것 › *도면 확인 필요* 4건은 원본 도면에 실제로 있는 문제입니다.
   - `P13` 도면명 철자 오기(VAVLE) · `P23` 도면명 미기재(표제란에 'TITLE') · `P26` 용접 기호 없이 크기만 · `P31` 도면명 8IN 과 치수 6.700 불일치
2. `P01 전면 수직 각관`: 기준 절단 길이 `55 ± 0.5 in`, 구멍 `12 개`, 구멍 지름 `0.813 ± 0.5 in`, 단면 규격 맞춰 볼 값 `□4.000×4.000×.250 R.250`.
3. `A` → 길이 `55.2` `Enter` → 구멍 `12` `Enter` → 지름 `0.813` → ✓ 합격. 구멍을 `11` 로 바꾸면 ✕ 불합격(`기준보다 −1 개`) → 사유 선택.
4. `W01` 용접 크기 기준 `≥ 0.13 in`: `0.1` 을 넣으면 `기준보다 0.03 in 부족` → 불합격.
5. 기준 바꾸기: `public/datasets/lifetrac-iii/recipes.json` 에서 `"id": "length"` 의 `"tol": 0.5` 를 `0.125` 로 고치고 새로고침하면 같은 55.2 가 불합격이 됩니다.
   개발 서버를 실행한 PC 에서만 할 수 있습니다. 배포용 빌드에서는 `dist/datasets/lifetrac-iii/recipes.json` 을 고칩니다.

## 기록 저장 · 옮기기

- 기록은 이 브라우저에 데이터별로 자동 저장됩니다. 저장할 수 없는 환경(시크릿 창 등)에서는 상단에 '저장 안 됨' 경고가 표시됩니다.
- **더보기 › 검사 결과 CSV**: 엑셀용 (한글 깨짐 방지 BOM 포함)
- **더보기 › 기록 JSON ↓ / 가져오기**: 다른 PC · 다른 사람과 기록 교환. 잘못 가져왔으면 `Ctrl(⌘)+Z`.

## 내 데이터 추가하기

1. 자료 준비: 부품 목록(엑셀) + 도면(이미지/PDF) + 검사 항목. 엑셀은 **CSV UTF-8(쉼표로 분리)** 로 저장 (일반 CSV 는 한글이 깨짐).
2. 생성형 AI 에 [dataset-schema.md](dataset-schema.md) 전체와 내 자료를 함께 주고 요청합니다.
   ```
   위 "데이터셋 형식" 문서에 맞춰 아래 자료로 데이터셋을 만들어 줘.
   - 데이터셋 id: mold-a, 분야: 금형
   - 도면 좌표계: 가로 0~800, 세로 0~600 (단위 mm), 면은 "상형"과 "하형" 2개
   - 파일: meta.json, items.csv, placements.csv, docs.csv, recipes.json
   - 부품 위치를 모르면 placements.csv 에서 빼고, 모르는 값은 비워 둬. 지어내지 마.
   [여기에 내 부품 목록 · 검사 항목 붙여넣기]
   ```
   **"모르면 비워 둬, 지어내지 마"** 가 중요합니다. 빈 위치 · 기준은 현황의 '확인할 것'에 자동으로 모입니다.
3. 도면 이미지를 쓰면 meta.json 의 `viewBox` 를 이미지 픽셀 크기로 맞춥니다 (예: 1600×1200 → `[0, 0, 1600, 1200]`, `"unit": "px"`). 좌표 = 픽셀 위치.
4. `public/datasets/mold-a/` 에 파일을 두고 `public/datasets/index.json` 에 한 줄 추가: `{ "id": "mold-a", "name": "A 금형", "domain": "금형" }`
5. 새로고침 → 왼쪽 위 데이터 선택 → 현황에서 대상 수와 확인할 것을 먼저 봅니다. 형식 오류 메시지가 나오면 그대로 AI 에 붙여 고쳐 달라고 합니다.

## 범위 밖

- 카메라 사진으로 불량을 자동 판정 (제품 사진과 합격 · 불합격 정답 데이터, 모델 학습 · 검증이 필요)
- 실물 사진 위에 CAD 좌표를 정밀하게 겹치기 (기준점 정렬 · 원근 보정 필요)
- 서버 · 여러 사람이 함께 쓰는 DB (지금은 브라우저 저장 + JSON 교환)
