# User guide

앱 안에서는 **사용 방법**(`?`) 창과 현황 상단 안내에 같은 내용이 있습니다.

## Workflow

1. 우측 상단 **검사자** 입력 — 기록마다 이름 · 시각 저장
2. 현황 → **검사 시작** — 남은 첫 항목이 열림
3. 도면의 파란 영역 = 위치. 면 · 시트 자동 전환, 작은 부품 자동 확대, PCB 는 **3D**
4. 기록 입력 → 즉시 판정
5. 불합격이면 **사유**, 판단 보류면 **보류**
6. `N` 으로 다음 → 끝나면 **성적서** → 인쇄 / PDF

## Check types

| 구분 | 입력 | 화면 보조 |
|---|---|---|
| `측정` | 수치 | 허용 범위 막대, 편차 (`+0.2 in · 허용 ±0.5 in`) |
| `육안` | 이상 없음 / 이상 | 맞춰 볼 값(품번 · 규격), 도면 ◆ (1번 패드) |
| `자동` | 없음 | 해당 없음 처리, 데이터 간 일치 비교 |

## Status

| ✓ | ✕ | ∥ | ◐ | ○ | – |
|---|---|---|---|---|---|
| 합격 | 불합격 | 보류 | 검사 중 | 미검사 | 검사 제외 |

## Shortcuts

| Key | Action |
|---|---|
| `N` | 다음 미검사 |
| `A` | 빈 '이상 유무' 칸 → 모두 이상 없음 |
| `Enter` | 다음 빈 입력칸 (HID 디지털 측정기 그대로 사용 가능) |
| `J` / `K` | 다음 / 이전 |
| `/` | 검색 |
| `Ctrl`/`⌘` `Z` | 되돌리기 |
| `?` | 사용 방법 |

## Examples

**PCB — `pcb-lightsabre`**

| 항목 | 확인할 것 |
|---|---|
| `U5` | ◆ = 1번 패드(DGND), 맞춰 볼 값 `ES9018K2M`, 데이터시트 링크 |
| `C1` | 극성 = 자동 해당 없음 → `A` 한 번에 합격. 칩 크기 BOM 0603 = CAD 0603 |
| `J6` | 뒷면 부품 → 도면이 뒷면(좌우 반전)으로 전환 |
| `FB1`, `Y1` | 검사 기준 없음 → 현황 › 검사 준비 안 됨 |

**LifeTrac — `lifetrac-iii`**

| 항목 | 확인할 것 |
|---|---|
| `P01` | 길이 `55 ± 0.5 in` · 구멍 `12 개` · 지름 `0.813 ± 0.5 in`. 구멍 `11` → 불합격 (`기준보다 −1 개`) |
| `W01` | 용접 크기 `≥ 0.13 in`. `0.1` → `기준보다 0.03 in 부족` |
| `P13` `P23` `P26` `P31` | 원본 도면 결함 → 현황 › 도면 확인 필요 |

기준 변경은 `recipes.json` 수정 후 새로고침 (예: `length` 의 `tol` 0.5 → 0.125 이면 55.2 가 불합격). 빌드본은 `dist/datasets/…` 를 수정.

## Records

- localStorage 에 데이터별 자동 저장. 저장 불가 환경(시크릿 창 등)은 상단에 경고
- 더보기 › **결과 CSV** (UTF-8 BOM, 엑셀용) · **기록 JSON** 내보내기 / 가져오기

## Adding your own data

1. 엑셀은 **CSV UTF-8** 로 저장
2. [dataset-schema.md](dataset-schema.md) + 내 자료를 생성형 AI 에 전달

   ```
   위 형식에 맞춰 아래 자료로 데이터셋을 만들어 줘.
   - id: mold-a, 분야: 금형
   - 좌표계: 0~800 × 0~600 mm, 면은 "상형" · "하형"
   - 파일: meta.json, items.csv, placements.csv, docs.csv, recipes.json
   - 모르는 값은 비워 둬. 지어내지 마.
   [부품 목록 · 검사 항목]
   ```
3. 도면 이미지는 `viewBox = [0, 0, 폭, 높이]`, `unit: "px"` 로 두면 좌표 = 픽셀
4. `public/datasets/<id>/` 에 저장, `public/datasets/index.json` 에 등록
5. 새로고침 → 오류 메시지가 나오면 그대로 AI 에 붙여 수정 요청

비워 둔 위치 · 기준은 현황 › 확인할 것에 자동으로 모입니다.

## Out of scope

- 영상 기반 불량 판정 (사진 + 정답 데이터 + 모델 필요)
- 실물 사진 – CAD 정밀 정합
- 서버 / 다중 사용자 DB
